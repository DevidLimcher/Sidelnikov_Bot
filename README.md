# Документация по проекту: Бот с интеграцией FAISS и LLaMA

Этот проект представляет собой бот на базе искусственного интеллекта, написанный на Python. Он использует FAISS для поиска схожих вопросов, SentenceTransformers для генерации эмбеддингов, а также модель LLaMA для генерации текстовых ответов. Бот обрабатывает пользовательские запросы, либо находя похожие вопросы в базе данных, либо создавая ответ при помощи генеративной модели.

## Зависимости

Проект использует следующие библиотеки:
- `aiogram`: библиотека для взаимодействия с API Telegram.
- `sentence-transformers`: для создания эмбеддингов вопросов.
- `transformers`: для работы с предварительно обученными моделями, такими как LLaMA.
- `faiss`: для быстрого поиска схожих эмбеддингов.
- `torch`: фреймворк для запуска моделей.
- `sqlite3`: для хранения вопросов и ответов.

Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Инструкции по установке

1. **Настройка базы данных**: Убедитесь, что файл `bot_database.db` создан в папке `database`, запустив `create_db.py` или добавив вопросы вручную.

2. **Создание индекса FAISS**: Используйте функцию `create_faiss_index` из `faiss_index.py` для инициализации FAISS индекса на основе вопросов из базы данных.

3. **Запуск бота**: Запустите бота, выполнив `bot.py`.

## Функциональность

Бот выполняет следующие задачи:
- **Отвечает на вопросы пользователей** с помощью поиска похожих вопросов в базе данных.
- **Генерирует ответы** при помощи модели LLaMA, если похожий вопрос не найден.
- **Управляет уровнями доступа пользователей** для контроля разрешений на добавление или редактирование вопросов и ответов.

## Команды и обработчики

### Основные команды

- **/start**: Отправляет приветственное сообщение в зависимости от уровня доступа пользователя.
- **/id**: Отправляет `user_id` пользователя.
- **/add_question**: Позволяет администраторам добавлять вопрос-ответ в базу данных.

### Обработчики

- `start`: Приветствует пользователя и сообщает его уровень доступа.
- `send_user_id`: Отправляет `user_id` пользователя в ответ на команду.
- `add_question`: Добавляет вопрос-ответ в базу данных, если пользователь — администратор.
- `handle_message`: Обрабатывает все текстовые запросы и генерирует ответ.

## Описание файлов

### `bot.py`
Основной файл для запуска бота. Создает диспетчер, регистрирует все необходимые роутеры и команды.

### `config.py`
Файл конфигурации, в котором хранятся настройки, такие как API токены.

### `faiss_index.py`
Содержит функции для создания и загрузки FAISS индекса для быстрого поиска схожих вопросов.

#### Основные функции:
- **create_faiss_index()**: Инициализирует и сохраняет FAISS индекс на основе эмбеддингов вопросов.
- **load_faiss_index()**: Загружает существующий индекс или создает новый, если его нет.

### `rag_.py`
Обрабатывает пользовательские вопросы, либо выполняя поиск в FAISS индексе, либо генерируя ответ с помощью LLaMA.

#### Основные функции:
- **find_similar_question(user_question)**: Выполняет поиск похожего вопроса в индексе FAISS.
- **process_user_question(user_question)**: Выполняет основную обработку ответа пользователю, вызывая `find_similar_question`.

### `handlers/handlers.py`
Управляет всеми командами и обработчиками бота, содержит функции для обработки каждой команды и запроса.

#### Основные обработчики:
- **start**: Приветствует пользователя в зависимости от уровня доступа.
- **add_question**: Позволяет администратору добавить вопрос-ответ в базу данных.
- **handle_message**: Обрабатывает все текстовые запросы и отправляет ответ.

### `database/add_admin.py`
Скрипт для добавления администратора в базу данных.

### `llama_model.py`
Управляет инициализацией модели LLaMA и настройками для генерации ответов на пользовательские запросы.

```

```

### Поиск похожих вопросов
Когда пользователь задает вопрос, бот:
1. **Ищет похожий вопрос в индексе FAISS**.
2. **Возвращает наиболее близкий вопрос** из базы данных, если схожесть выше порогового значения.
3. **Генерирует ответ** с помощью LLaMA, если схожий вопрос не найден.
